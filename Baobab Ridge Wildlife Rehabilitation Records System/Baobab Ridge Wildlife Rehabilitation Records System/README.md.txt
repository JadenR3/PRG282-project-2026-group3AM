## How to Build and Run
1. Clone this repository.
2. Open `BaobabRidge.sln` in Visual Studio 2022.
3. Build the solution (Ctrl + Shift + B).
4. Run (F5). The app opens with data loaded from `animals.txt`.

## Features
- Add a new animal
- View all animals
- Update an existing animal
- Delete an animal
- Generate summary report (summary.txt)

## File Formats
- **animals.txt**: 7 pipe-separated fields (ID|Name|Species|Age|Score|Status|Housing Unit)
- **summary.txt**: Generated each time summary is run (overwritten each time)

## Known Limitations
- Data stored in plain text only.
